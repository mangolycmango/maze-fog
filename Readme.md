# 迷雾终端迷宫 (Maze‑Fog)
> 版本：v1.0.0
> 语言：Python 3
> 许可证：MIT

## 📖 项目简介
这是一款运行在终端里的文字迷宫探索游戏，核心特色为**迷雾探索机制**。地图会生成大量墙体，但初始状态墙体对玩家不可见，**只有玩家主动撞到墙体之后，该墙体才会显示在地图上**。玩家需要在视野受限的条件下，依靠不断碰壁探明迷宫布局，寻找目标点位。

项目完全使用 Python 内置标准库实现，无需安装任何第三方依赖包，只要环境具备 Python3 即可直接运行。游戏内置炸弹传送机制、动态更换目标点、完整游戏对局数据统计等功能。整体采用面向过程编写，代码逻辑直白，适合 Python 初学者阅读、学习以及二次修改。

地图固定为 30×30 大小，每次启动游戏会随机生成墙体、炸弹点位、玩家出生点与目标点，每一局地图都不完全相同，具备重复游玩价值。

## ✨ 主要功能特性
1. **迷雾探索系统**
地图墙体默认隐藏，发生撞墙行为后才渲染对应墙体；系统会自动清理久远的撞墙记忆，不会永久记住全部墙体，维持探索压力。

2. **炸弹随机传送机制 💣**
地图随机生成若干炸弹点位。当玩家踩到炸弹，炸弹会消失，玩家将被随机传送到地图上一处安全空地，增加游戏不确定性与挑战性。

3. **动态更新目标点 🔷**
玩家每成功移动满100步，系统会自动重新随机生成一个全新的目标点，旧目标失效，迫使玩家继续探索迷宫。切换目标时会给出文字提示。

4. **完整游戏数据统计**
游戏全程统计：成功移动步数、游戏总耗时，到达终点时计算平均每一步消耗时间，通关后完整展示对局统计信息。

5. **调试辅助功能**
内置调试指令，方便开发、测试：一键显示整张完整迷宫地图；导出当前完整地图原始坐标数据，可直接复现对局。

6. **跨平台清屏适配**
自动识别 Windows / Linux / macOS 操作系统，执行对应清屏命令，刷新游戏画面。

## 🎮 操作说明
启动程序后，在终端输入数字并按下回车执行操作：

| 输入数字 | 功能 |
|--------|------|
| 1 | ⬅️ 向左移动 |
| 2 | ➡️ 向右移动 |
| 3 | ⬆️ 向上移动 |
| 4 | ⬇️ 向下移动 |
| 5 | 调试：显示完整全部地图（展示所有墙体与炸弹），也可人工审核迷宫是否通路 |
| 6 | 调试：⚠️可执行任意python单行代码，普通用户版本必须删除此段代码，防止执行恶意代码 |
| 7 | 调试：打印导出当前地图原始坐标数据，可直接复制使用，恢复墙壁、玩家、炸弹、目标点、撞墙记录、步数，复现当前对局 |
| 0 | 退出游戏程序 |

> 注意：移动指令执行后，需要按下回车确认输入。碰到边界、墙体时移动会被拒绝，并给出提示文字。

## 🚀 运行要求
- Python 版本：Python 3.6 及以上
- 终端环境：
  - 推荐：Windows Terminal、PowerShell、iTerm2、Linux终端
  - Windows 传统 CMD：会存在 emoji 显示方块乱码、清屏效果异常问题，不建议使用。

> 使用方式：下载 main.py，使用 Python3 直接运行该脚本即可启动游戏。

## ⚠️ v1.0.0 版本已知限制与现存问题
> 下列为本版本固有局限，并非全部为程序BUG，部分为设计取舍，会在后续版本迭代优化：
1. 一局游戏通关之后，不支持游戏内重新开局。想要新开一局迷宫，需要关闭程序，重新运行脚本。
2. 地图完全随机生成，没有通路校验逻辑。极端随机情况下，目标点有可能被墙体完全包围，造成本局无法通关。
3. 撞墙记忆存在有效期，只会保留最近10次成功移动内产生的撞墙记录；更早撞过的墙体将会重新隐藏。
4. 游戏使用Emoji表情符号绘制地图，老旧终端、部分服务器终端缺少对应字体，会显示为方框、问号等乱码字符。
5. 全部交互依靠输入数字+回车，不支持方向键直接控制，每一步操作都需要按下回车确认。
6. 踩到炸弹💣会直接随机传送玩家，当前版本没有文字提示，玩家会发生无提示瞬移。
7. 指令 6 为开发者调试后门，对外面向普通用户分发版本时，需要删除对应代码块，避免任意代码执行风险。
