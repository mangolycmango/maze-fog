# 迷雾终端迷宫 (Maze-Fog)

版本：v1.2.0 ｜ 语言：Python 3 ｜ 许可证：MIT

## 📖 项目简介

这是一款运行在终端里的文字迷宫探索游戏，核心特色为**迷雾探索机制**。地图会生成大量墙体，但初始状态墙体对玩家不可见，**只有玩家主动撞到墙体之后，该墙体才会显示在地图上**。玩家需要在视野受限的条件下，依靠不断碰壁探明迷宫布局，寻找目标点位。

v1.2.0 在保留 v1.1.0 全部能力（A\* 通路校验、迷宫难度系统、炸弹传送、动态目标点、调试终端）的基础上，重点补齐了**对局存档/读档闭环**与**体验打磨**：

- **存档方式重构**：v1.1 的“复制粘贴代码回源码”方式升级为**一键写入 maze.dat + 启动自动读档**，无需改代码即可断点续玩；
- **命令行固定种子**：`python3 main.py <数字>` 可复现同一局迷宫，方便测试与交流；
- **炸弹传送提示**：踩到炸弹时明确告知“被随机传送到安全空地”，不再无提示瞬移；
- **通关后重新开局**：通关结算后询问“是否重新开始？”，选 y 立即开新一局，无需重启脚本；
- **参数集中配置区**：地图大小、难度下限、撞墙记忆时长、墙体/炸弹数量范围、目标刷新步数全部集中到源码顶部，一行一常量；
- **输入健壮性**：非法输入校验、退出二次确认、Ctrl+C 安全退出。

⚠️ 注意：v1.1.0 起引入第三方依赖库 `pathfinding`（A\* 寻路），运行前需要执行 `pip install pathfinding`，不再像 v1.0.0 那样纯标准库零依赖。

## ✨ 主要功能特性

1. **迷雾探索系统**：地图墙体默认隐藏，发生撞墙行为后才渲染对应墙体；系统会自动清理久远的撞墙记忆（记忆时长可配置，默认最近 10 步），不会永久记住全部墙体，维持探索压力。

2. **A\* 寻路通路校验**：使用 A\* 算法（pathfinding 库）在生成地图时计算玩家到目标点的最短路径，只采用存在可达路径的地图，杜绝“死图”无法通关。每 100 步刷新目标点、踩炸弹传送落点同样会经过可达性校验。

3. **迷宫难度系统**：难度值由玩家到目标点的**最短路径长度**计算：难度 = 最短路径格数 ÷ 58 × 5.0（保留 1 位小数）。默认要求难度不低于 5.0（即最短路径不少于 58 格），不达标的地图自动重新生成，生成成功时打印“本次迷宫难度:X，一共尝试生成 N 次”。最低难度可在源码顶部 `MIN_DIF` 处修改。

4. **炸弹随机传送机制 💣**：地图随机生成若干炸弹点位。当玩家踩到炸弹，炸弹会消失，玩家将被随机传送到地图上一处安全空地（该落点保证仍有通往目标的路径），并给出“💣 踩到炸弹！被随机传送到安全空地”的提示（v1.2 新增），增加游戏不确定性与挑战性。

5. **动态更新目标点 🔷**：玩家每成功移动满一定步数（默认 100，可配置），系统会自动重新随机生成一个全新的目标点，旧目标失效，迫使玩家继续探索迷宫。切换目标时会给出文字提示，且新目标点保证可达。

6. **完整游戏数据统计**：游戏全程统计成功移动步数、游戏总耗时，到达终点时计算平均每一步消耗时间，通关后完整展示对局统计信息。

7. **对局存档 / 自动读档（v1.2 重构）**：游戏内按指令 7 可将当前完整对局（墙体、玩家、目标、炸弹、撞墙记录、步数、难度、最短路径、出生点）一键写入 `maze.dat`；下次启动程序时**自动检测并读档**，直接回到存档时的局面，无需修改源码。删除 `maze.dat` 即可回到随机开局。

8. **固定随机种子（v1.2 新增）**：启动时可附带一个数字参数 `python3 main.py 42`，同一数字会生成完全相同的迷宫，便于复现对局、测试与讨论。

9. **通关后重新开局（v1.2 新增）**：通关结算界面会询问“是否重新开始？(y/n)”，选 y 立即随机生成一局全新迷宫继续挑战，选 n 退出程序，全程无需重启脚本。

10. **调试辅助功能**：内置调试指令，方便开发、测试：一键显示整张完整迷宫地图；密码保护的任意 Python 代码执行终端（eval / exec 两种模式）；显示 A\* 最短路径（🟦 标记）辅助审核迷宫。

11. **跨平台清屏适配**：优先使用 ANSI 转义序列清屏，失败时自动识别 Windows / Linux / macOS 操作系统执行对应清屏命令，刷新游戏画面。

12. **输入健壮性（v1.2 新增）**：非数字输入给出“输入无效”提示；退出指令 0 增加 y/n 二次确认防止误退；Ctrl+C 不再直接报错而是安全退出。

## 🎮 操作说明

启动程序后，在终端输入数字并按下回车执行操作：

| 输入数字 | 功能 |
|---|---|
| 1 | ⬆️ 向上移动 |
| 2 | ⬇️ 向下移动 |
| 3 | ⬅️ 向左移动 |
| 4 | ➡️ 向右移动 |
| 5 | 调试：显示完整全部地图（展示所有墙体与炸弹），也可人工审核迷宫是否通路 |
| 6 | 调试：⚠️ 默认需要密码的任意 Python 单行代码执行终端（输入 `eval` 或直接回车为 eval 模式，输入其他任意内容为 exec 模式），**普通用户版本必须删除此段代码**，防止执行恶意代码 |
| 7 | 存档：将当前完整对局写入 `maze.dat`，下次启动自动读档恢复 |
| 8 | 调试（隐藏指令）：直接传送到目标点，可秒通关，用于快速测试 |
| 9 | 调试（隐藏指令）：显示从出生点到目标点的 A\* 最短路径（🟦 标记），用于人工审核迷宫通路 |
| 0 | 退出游戏程序（需再按 y 确认） |

注意：移动指令执行后，需要按下回车确认输入。碰到边界、墙体时移动会被拒绝，并给出提示文字。指令 8 / 9 为隐藏调试指令，不会出现在游戏顶部操作提示中。**通关后程序会询问“是否重新开始？(y/n)”**，选 y 开新一局，选 n 退出。

## ⚙️ 参数配置区（v1.2）

所有可调参数集中在源码顶部，修改后保存即可生效：

| 常量 | 默认值 | 含义 |
|---|---|---|
| `k` / `kk` | 30 / 30 | 地图宽 / 高（格数） |
| `MIN_DIF` | 5.0 | 最低难度值（最短路径不足则该地图作废重生成） |
| `WALL_MEMORY` | 10 | 撞墙记忆保留的步数，超过该步数后墙体重新隐藏 |
| `MIN_WALLS` / `MAX_WALLS` | 80 / 360 | 每局随机墙体数量范围 |
| `MIN_BOMBS` / `MAX_BOMBS` | 2 / 10 | 每局炸弹数量范围 |
| `TARGET_REFRESH` | 100 | 目标点自动更换的间隔步数 |
| `MAX_LEN` | 58 | 难度计算基准：最短路径满 58 格记难度 5.0 |

## 🚀 运行要求

- Python 版本：Python 3.6 及以上
- 第三方依赖：**pathfinding**（A\* 寻路库），运行前执行 `pip install pathfinding`
- 终端环境：
  - 推荐：Windows Terminal、PowerShell、iTerm2、Linux 终端
  - Windows 传统 CMD：会存在 emoji 显示方块乱码、清屏效果异常问题，不建议使用

使用方式：

```bash
pip install pathfinding
python3 main.py            # 随机开局
python3 main.py 42         # 使用固定种子开局，同一数字可复现同一迷宫
```

如果目录下存在 `maze.dat`，程序会自动读档续玩；删除该文件后恢复随机开局。

## ⚠️ v1.2 版本已知限制与现存问题

下列为本版本固有局限，并非全部为程序 BUG，部分为设计取舍，会在后续版本迭代优化：

1. 撞墙记忆存在有效期（默认最近 10 步内），更早撞过的墙体将会重新隐藏；此行为为迷雾玩法设计，可通过 `WALL_MEMORY` 调整。

2. 游戏使用 Emoji 表情符号绘制地图，老旧终端、部分服务器终端缺少对应字体，会显示为方框、问号等乱码字符。

3. 全部交互依靠输入数字+回车，不支持方向键直接控制，每一步操作都需要按下回车确认。

4. 指令 6 为开发者调试后门（默认开启密码保护，密码校验使用 PBKDF2-SHA512、300 万次迭代哈希），指令 8 / 9 为隐藏作弊指令，对外面向普通用户分发版本时，需要删除对应代码块，避免任意代码执行与作弊风险。

5. v1.1.0 起引入第三方依赖 pathfinding，不再像 v1.0.0 那样纯标准库零依赖；离线或受限网络环境需提前安装好该库才能运行。

6. 最低难度 `MIN_DIF` 设置过高时，满足难度要求的地图可能较难生成，程序会自动重试（并打印尝试次数），极端情况下开局生成耗时可能明显变长。

7. `maze.dat` 存档内容与 v1.2 的数据结构绑定，与其他版本代码互不通用；存档文件损坏时程序会静默忽略并重新随机开局。

8. 固定随机种子仅保证在**同版本、同参数配置**下复现同一迷宫，修改配置区参数后同一数字会生成不同地图。

## 📅 版本迭代规划

规则：接下来 3 个非 BUG 修复小版本（v1.3 / v1.4 / v1.5），至少完成下面列表中的一半功能。

- [ ] **阶段制闯关（核心）**：通关后进入下一阶段，界面显示“第 N 阶段”；地图尺寸、墙体数量、炸弹数量、目标刷新步数随阶段逐级提升（30×30 → 35×35 → 40×40），难度平稳爬坡。玩家的目标从“过完一局”变成“能闯到第几阶段”，重开不再是无意义的同一难度循环
- [ ] **传送门机制 🌀**：每阶段随机生成 1~2 对传送门，踩入即被传送到配对传送门所在位置（落点经过可达性校验），打破单调探路，增加路线变数
- [ ] **探索度结算**：通关时统计本局已探索格数占迷宫总格数的百分比、玩家实际路径长度，与 A\* 最短路径并排对比，直观看出“绕了多少路”
- [ ] **阶段记录（本机排行）**：自动保存历史最高阶段、各阶段最少通关步数与最短用时，下次开局展示“上次战绩”，形成长期挑战目标
- [ ] **键盘方向键直接移动**：免除每次输入数字+回车，Windows 使用 `msvcrt`、类 Unix 使用 `getch` 读取按键

**v1.2 完成情况**：上一轮规划列表 3 项（参数配置区、炸弹传送提示、游戏内重新开局）全部完成；此外额外落地了对局存档/读档闭环（maze.dat 自动读档）、命令行固定种子、输入校验与退出确认、非法输入拦截等体验增强。

## ⚖️ 有争议功能（不会直接开发，需要评估平衡性、趣味性、公平性）

这类功能改动会改变游戏原有体验，实现之前需要评估会不会破坏游戏平衡，思考、投票后再决定要不要做：

- 给玩家赠送有限次数穿墙能力，消耗次数可以直接穿过一堵墙
- 赠送有限次数“全图透视”，短时间看到整张迷宫全部墙体与炸弹
- 增加道具系统：护盾、回溯步数（回退上几步操作）
- 负面道具：比如短暂抹除部分已经探开的迷雾，重新隐藏部分已知墙体
